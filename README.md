# LOLZ Market Аналізатор

Панель для моніторингу лотів на lzt.market.

## Встановлення

```bash
pip install -r requirements.txt
python main.py
```

## Використання

1. Вставте URL пошуку з lzt.market (наприклад фільтр по UA Telegram акаунтам)
2. Вкажіть кількість лотів для аналізу (1–20)
3. Натисніть **Пошук**
4. Зелені рядки — ваші лоти, білі — чужі
5. Подвійний клік по рядку — відкриває лот у браузері
